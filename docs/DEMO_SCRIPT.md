# Five-minute demo

1. Explain roles, private storage and document-level permissions.
2. Register Owner and upload a harmless PDF/TXT.
3. Admin provisions second account as Viewer.
4. Owner grants Read; Viewer opens/downloads.
5. Owner revokes; Viewer retries same URL and is denied.
6. Grant Edit to another account; demonstrate metadata edit and Read-only denial.
7. Show audit integrity and file-integrity test evidence.

Use synthetic files/accounts. Never fabricate test results.
